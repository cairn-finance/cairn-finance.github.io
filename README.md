# Cairn website compatibility

This repository serves the existing Cairn website paths at
https://cairn-finance.github.io/cairn/. These pages keep privacy-policy and
support links in released app versions working when the app source repository
changes owners.

The app source and current website sources are maintained in
[Cairn](https://github.com/sehejjain/cairn).

The `pages` branch publishes from the repository root. The `cairn/` directory
contains the homepage, privacy policy, support page, and stylesheet. Keep these
pages current with the published website when policy or support details change.

The website content retains Cairn's Apache 2.0 license and notices.
